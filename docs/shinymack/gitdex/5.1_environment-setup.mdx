# Environment Setup

This section details the configuration requirements for the GitDex environment, covering client-side documentation mappings, MDX configuration, and server-side compilation settings.

## Client-Side Configuration

The client environment utilizes a structured configuration to manage UI components and documentation rendering. This is primarily handled through the CLI configuration and source configuration files.

### Path Aliases and UI Framework
The project uses a specific alias mapping to streamline imports across the `src` directory. The UI layer is built upon the `radix-ui` library.

| Alias | Path | Description |
| :--- | :--- | :--- |
| `uiDir` | `./src/components/ui` | Core UI primitive components |
| `componentsDir` | `./src/components` | General shared components |
| `blockDir` | `./src/components` | Documentation layout blocks |
| `cssDir` | `./src/styles` | Global and modular stylesheets |
| `libDir` | `./src/lib` | Utility functions and shared libraries |

```json
// client/cli.json
{
  "baseDir": "src",
  "uiLibrary": "radix-ui"
}
```

### Documentation and MDX Setup
GitDex employs `fumadocs-mdx` for content generation. The documentation environment is configured to support specialized rendering plugins, including Mermaid for technical diagrams.

**Core Configuration Dependencies:**
- `defineDocs` & `defineConfig`: Used for initializing documentation settings.
- `remarkMdxMermaid`: Plugin enabling the rendering of Mermaid diagrams within MDX files.

```typescript
// client/source.config.ts
import { defineDocs, defineConfig } from 'fumadocs-mdx/config';
import { remarkMdxMermaid } from 'fumadocs-core/mdx-plugins';
```

## Server Configuration

The backend environment is configured for a modern Node.js runtime, focusing on strict type safety and compatibility with the `ESNext` standard.

### TypeScript Compiler Options
The `server/tsconfig.json` ensures a consistent build environment. Key configurations are summarized below:

| Option | Value | Impact |
| :--- | :--- | :--- |
| `target` | `ESNext` | Compiles to the latest ECMAScript standard |
| `module` | `Preserve` | Maintains module structure for the bundler |
| `moduleResolution` | `bundler` | Optimizes resolution for modern bundling tools |
| `strict` | `true` | Enables all strict type-checking options |
| `noUncheckedIndexedAccess` | `true` | Forces checks for `undefined` when accessing arrays/objects |

```json
// server/tsconfig.json
{
  "compilerOptions": {
    "lib": ["ESNext"],
    "target": "ESNext",
    "strict": true,
    "noEmit": true
  }
}
```
