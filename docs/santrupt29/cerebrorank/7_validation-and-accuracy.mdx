# Validation and Accuracy

To ensure the mathematical integrity of the custom ranking algorithms implemented from scratch, the system performs cross-validation against industry-standard implementations provided by the `networkx` library. This process compares the custom PageRank and HITS (Hubs and Authorities) results against `nx.pagerank()` and `nx.hits()` using several statistical metrics.

The validation logic is centralized in [core/validation.py](https://github.com/santrupt29/cerebrorank/blob/32f8ca14fe1a4de04497d11e942f9c7432d264d1/core/validation.py).

## Validation Methodology

The system evaluates accuracy by comparing the distribution and ranking order of the custom scores against the NetworkX benchmarks.

### Normalization Handling
A key technical detail in the validation process is the handling of score scales:
* **PageRank:** Since both the custom implementation and `nx.pagerank()` produce vectors that already sum to 1, no additional renormalization is required.
* **HITS:** The custom HITS implementation uses **L2 normalization**, whereas NetworkX normalizes scores so they sum to 1. To ensure a fair comparison of the distribution "shape" rather than the scaling convention, the system renormalizes the custom H2 (Hub) and Authority vectors to sum to 1 before computing error metrics via the `_renorm` function in [core/validation.py](https://github.com/santrupt29/cerebrorank/blob/32f8ca14fe1a4de04497d11e942f9c7432d264d1/core/validation.py).

### Metrics Used
The following metrics are computed for both PageRank and both HITS components (Hubs and Authorities):

| Metric | Description |
| :--- | :--- |
| **MSE** | Mean Squared Error; measures the average squared difference between custom and benchmark scores. |
| **Spearman rho** | Measures the monotonic relationship between the two sets of rankings. |
| **Kendall tau** | Measures the ordinal association (rank correlation) between the two sets. |
| **Top-10 Overlap** | The count of common nodes found in the top 10 highest-ranked entities in both implementations. |
| **Max Absolute Error** | The single largest difference found between corresponding node scores. |

## Execution and Output

Validation is automatically triggered during the `rank` command in [main.py](https://github.com/santrupt29/cerebrorank/blob/32f8ca14fe1a4de04497d11e942f9c7432d264d1/main.py).

### CLI Command
```bash
python main.py rank
```

### Reporting
When the `rank` command is executed, the system performs the following:
1. Runs the custom PageRank and HITS algorithms.
2. Invokes `validate_all()` to compare results against NetworkX.
3. Prints a summary table to the console (as defined by `_print_validation_summary` in [main.py](https://github.com/santrupt29/cerebrorank/blob/32f8ca14fe1a4de04497d11e942f9c7432d264d1/main.py)).
4. Persists the full detailed report to a JSON file at the path specified in `cfg.validation_path`.
