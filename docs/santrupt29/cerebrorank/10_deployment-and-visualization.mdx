# Deployment and Visualization

The [app.py](https://github.com/santrupt29/cerebrorank/blob/32f8ca14fe1a4de04497d11e942f9c7432d264d1/app.py) script serves as an interactive, multi-tab offline dashboard for the MarvelGraphRank project. It allows users to explore the results of the PageRank and HITS ranking processes through various lenses, including live parameter manipulation and network inspection.

## Overview

The dashboard is built using **Streamlit** and is designed to work entirely offline, provided that the necessary data files (`data/edgelist.csv`, `data/nodes.csv`, and `data/scores.csv`) have been generated via the CLI pipeline.

### Core Functionalities
*   **Live Parameter Exploration:** Adjust the PageRank damping factor ($d$) to observe how influence distributions shift in real-time.
*   **Interactive Ranking Tables:** View and filter top-ranked entities across PageRank, HITS Authority, and HITS Hub scores.
*   **Node Inspection:** Access detailed metadata for specific nodes, including in-degree, out-degree, and semantic node types (e.g., 'character', 'film').
*   **Community Detection:** Visualize the graph's structure through Louvain community detection results.
*   **Filtering:** Refine views by semantic `node_type` or by excluding compilation/index pages (e.g., "List of..." pages).

## Dashboard Configuration and Controls

The application utilizes a sidebar for global configuration and filtering, affecting all subsequent visualizations and tables.

### Sidebar Parameters
| Parameter | Type | Description |
| :--- | :--- | :--- |
| **PageRank Damping Factor ($d$)** | Slider | Sets the probability of following outgoing links ($0.50$ to $0.99$). |
| **Top-K Elements** | Slider | Controls the number of top-ranked nodes displayed ($5$ to $50$). |
| **Filter Node Types** | Multiselect | Includes or excludes specific semantic categories defined in `config.yaml`. |
| **Exclude 'list' pages** | Checkbox | A toggle to filter out Wikipedia list/index articles. |

## Data Integration

The dashboard synthesizes several data sources to provide a unified view of the graph:

1.  **Graph Structure:** Loaded via `load_graph` from the processed CSVs.
2.  **Precomputed Scores:** Uses the `scores.csv` file for static HITS scores.
3.  **Live Computations:** Re-calculates PageRank on-the-fly using `pagerank()` from [core/algorithms.py](https://github.com/santrupt29/cerebrorank/blob/32f8ca14fe1a4de04497d11e9c7432d264d1/core/algorithms.py) when the damping factor is adjusted.
4.  **Community Mapping:** Uses `nx.community.louvain_communities` to assign nodes to identified clusters.

### Unified Score Schema
The `build_unified_scores_df` function aggregates these sources into a single DataFrame with the following columns:
*   `id`: Node index.
*   `title`: Wikipedia article title.
*   `pagerank`: Calculated PageRank score.
*   `authority`: HITS Authority score.
*   `hub`: HITS Hub score.
*   `in_degree` / `out_degree`: Connection counts.
*   `node_type`: Semantic classification (e.g., `person`, `tv_series`).
*   `community_id` / `community`: Louvain community assignments.

## Running the Dashboard

To launch the interactive environment, ensure you have first completed the data processing pipeline via the CLI, then execute:

```bash
streamlit run app.py
```

> **Note:** If the dashboard reports `⚠️ Graph data not found!`, ensure you have run `python main.py build`, `python main.py rank`, and `python main.py report` to generate the required `data/` directory files.
